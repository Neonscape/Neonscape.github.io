场景设定：“前夜”

概述

  • 场景名称：“前夜”
  • 场景类型：教学关卡
  • 核心目标：
    1. 教学玩家熟悉以下游戏机制：
      • 基础移动：行走、疾跑、跳跃、下蹲、攀爬
      • TPS基础操作：瞄准、开火、切换武器、切换视角、换弹
      • 角色技能基础：技能充能机制、技能激活、技能冷却和技能的使用技巧（战斗与探索）
    2. 引入世界观，给玩家留下关于游戏世界的大致印象。
  • 时长预计：8分钟

主题

  • 地区背景：霜锋区，北里附近的前哨站，训练场，雪夜
  • 美术风格：
    • 色调较为灰暗写实，以雪地、铁丝网、钢铁构筑和混凝土设施为主要元素，带有一些科技感的点缀
    • 以冷色调的环境和暖色的灯光形成对比
  • 主要情绪：
    • 寒冷、略为破败但较为安全
    • 迷茫
  • 声效：冷冽的风、铁丝网的声音、机械装置的声音、远处传来的枪声和踩在雪上的声音

关卡流程

该关卡的流程主要分为四部分，线性连接：

  1. 田径场：基础移动、冲刺、视角移动和交互教学区域
  2. 靶场：基础战斗教学区域（武器的基础使用）
  3. 开放式靶场：能力教学区域（技能的充能、冷却和使用）
  4. 结算区域（教学结束）

美术资产需求

通用预制体

  • 铁丝网墙面
  • 铁丝网门
  • 水泥墙面
  • 水泥地面
  • 金属预制板地面
  • 金属预制板墙面
  • 金属预制板门
  • 金属物资箱
  • 折叠桌
  • 金属梁

功能性预制体

  • 物资箱
  • 初始武器
  • 立式照明灯
  • 探照灯
  • 金属梯子

靶场

  • 训练假人
  • 距离标牌
  • 靶位隔断
  • 靶桌

开放式靶场

  • 训练机器人（有动画、可射击）

田径场

  • 低矮的水泥掩体（用于翻越）
  • 较高的水泥掩体（用于攀爬）

装饰

  • 纸箱
