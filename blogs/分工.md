# 分工

## 美术类

| 岗位            | 主要职责                   | 输入（Input）                  | 输出（Output）                 |
| --------------- | -------------------------- | ------------------------------ | ------------------------------ |
| 概念 / 场景设计 | 整体世界视觉风格与氛围     | 世界观设定、剧情概要、关卡需求 | 场景设计图                     |
| 角色设计        | 角色外观、服装、武器风格   | 角色设定文档、剧情定位         | 角色原画、表情设定、武器设定图 |
| UI 美术         | 设计UI风格                 | 系统设计文档                   | UI设计图、UI贴图               |
| 场景美术        | 依据概念图搭建3D场景与道具 | 概念设计图、关卡布局           | 场景模型、贴图、灯光           |
| 角色美术        | 角色建模、贴图与骨骼绑定   | 角色原画、比例设定             | 角色模型                       |
| 动画            | 角色动作资产               | 角色模型、动作需求表           | 动作序列                       |

## 文案类

| 岗位     | 主要职责                 | 输入（Input）          | 输出（Output）             |
| -------- | ------------------------ | ---------------------- | -------------------------- |
| 剧情设计 | 故事结构、情节与对白     | 世界观设定、角色设定   | 剧情脚本                   |
| 任务设计 | 将剧情转化为可玩任务逻辑 | 剧情脚本、玩法需求     | 任务JSON                   |
| 世界文本 | 游戏内文案与叙事碎片     | 世界观、物品与任务清单 | 道具说明表、日志、环境文本 |

## 策划类

| 岗位     | 主要职责                     | 输入（Input）                | 输出（Output）                   |
| -------- | ---------------------------- | ---------------------------- | -------------------------------- |
| 系统策划 | 设计玩法系统、数值、成长机制 | 玩法需求                     | 系统设计文档、数值表             |
| 关卡设计 | 规划场景结构与玩家节奏       | 剧情脚本、玩法目标、概念设计 | 关卡草图、敌人配置表、触发事件表 |
| 玩法策划 | 核心玩法、战斗循环           | 系统框架、剧情目标           | 玩法设计文档                     |

## 音频类

| 岗位     | 主要职责                       | 输入（Input）                  | 输出（Output） |
| -------- | ------------------------------ | ------------------------------ | -------------- |
| 音效设计 | 制作环境、交互、动作、战斗音效 | 动画事件表、关卡节奏、玩法说明 | 音效文件       |
| 作曲     | 编写场景与战斗音乐             | 概念图、剧情节奏、场景氛围     | 音乐文件       |
